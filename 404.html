GitHub Pages の設定切り替えが必要です

現在、GitHub Pages の配信元がビルド前の main ブランチに設定されているため、画面が表示されていません。ビルド済みの gh-pages ブランチ または GitHub Actions に切り替えてください。

【切り替え手順（30秒）】
  1. GitHubリポジトリの 「Settings」（設定）タブを開く
  2. 左サイドバーの 「Pages」 をクリック
  3. 「Build and deployment」 内の Branch を main から 『gh-pages』 に変更して 「Save」 を押す（または Source を 『GitHub Actions』 に変更）

※設定保存後、約1分でアプリが正常に起動します。
